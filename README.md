# Replace on Render

Write text replacement rules
for Live Preview and Reading Views.
Get the aesthetics of full-Unicode typography
with pure ASCII source code.

## Known Issues

- Replacements are not decorated correctly in certain contexts in Live Preview.
    - Replacements are not underlined in link text.
    - Replacements are not faded in link text for nonexistent notes.

- Replacements fail in most special contexts in Reading View.
